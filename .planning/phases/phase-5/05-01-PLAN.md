# Plan: GSD Security Threat Model Review

This plan details the STRIDE threat model verification for the completed task and workload management components.

---

## <threat_model>

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| THR-01    | Spoofing | AuthContext User Dropdown | Mitigated | `switchUser()` immediately calls `clearCache()` to purge tasks and notifications before loading the new user profile. |
| THR-02    | Tampering | TaskController API | Mitigated | Laravel requests validate incoming `priority` and `status` inputs against strict enum lists. |
| THR-03    | Information Disclosure | getMyTasks API Endpoint | Mitigated | Employees only fetch tasks linked via the `task_user` pivot table; they are locked out of the Admin index. |
| THR-04    | Elevation of Privilege | React Router Routes | Mitigated | `ProtectedRoute` blocks non-admin users from rendering administrative components. |
